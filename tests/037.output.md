# Ordered Lists

Non-list line.
1. First item.
2. Second item.
3. Third item.

Now let's try interrupting the list but not adding a blank line after this.
4. Fourth item.
5. Fifth item.

Now let's try a list in a quote block.

> This is my first list.
> 
> 1. List item.
> 2. List item.
> 3. List item.
> 
> Interruption.
> 
> 4. List item.
> 5. List item.
> 
> Now we try it without the blank line.
> 1. List item.
> 2. List item.
> 
> And we're done.

So done.
